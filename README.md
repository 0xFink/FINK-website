# BaalRock ($FINK) website

Info hub for BaalRock (ticker: FINK), a parody meme coin on PulseChain: contract address, launch portal, charts and liquidity, supply and burns, staking, timeline, and updates.

Single-file static site (`index.html`) served with GitHub Pages. No wallet connection on this site.

Not financial advice. See the disclaimer at the bottom of the site.
